This repository documents the end-to-end development work completed during the Web Development Internship. The curriculum focuses on building practical engineering capabilities across modern web architecture, beginning with fundamental frontend development and advancing toward secure, production-grade full-stack systems. Every task adheres strictly to industry standards, modular code organization, and secure data handling practices.

# Phase 1: Core Fundamentals & Interactive Layouts
The initial phase emphasizes foundational web technologies and responsive UI engineering. Development began with semantic HTML5 structures and responsive CSS layouts, highlighted by a personal portfolio interface. Progressing into dynamic behavior, vanilla JavaScript was implemented to manage the DOM and handle browser events. The layout engineering was further enhanced using modern CSS Flexbox and CSS Grid systems to construct adaptable multi-device galleries, an interactive to-do list powered by local storage persistence, and a modular calculator built using React state management.

# Phase 2: Full-Stack Integration & Database Systems
The advanced segment transitions into complete client-server architectures integrated with relational database management. A full-stack CRUD task manager was designed using Node.js and Express to expose performant REST APIs, connected directly to a local PostgreSQL instance via connection pooling. The React frontend interacts seamlessly with these endpoints to perform live create, read, update, and delete operations without manual page reloads.

# Phase 3: Application Security & Session Control
To establish enterprise-level reliability, a robust authentication system was deployed using cryptographic safeguards. Passwords are securely hashed with bcryptjs salt algorithms prior to persistence in PostgreSQL. User session management utilizes JSON Web Tokens (JWT), enabling stateless authentication between the client and protected server routes. The React application securely stores authentication state, provides dedicated registration and login views, and verifies JWT signatures before granting access to sensitive dashboard resources.
